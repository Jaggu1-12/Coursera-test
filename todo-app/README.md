# To-Do List Application

A modern, fully-featured to-do list app built with Vue 3 and Vite with complete local storage support.

## Features

✨ **Core Functionality**
- Add, edit, and delete tasks
- Mark tasks as complete/incomplete
- Persistent storage using browser's localStorage
- Automatic data sync

📊 **Task Management**
- Filter tasks (All, Active, Completed)
- Search functionality
- Due date support
- Priority levels (High, Medium, Low)
- Task categories

📱 **User Experience**
- Beautiful, modern UI
- Smooth animations
- Responsive design
- Undo/Redo functionality
- Task statistics

## Installation

```bash
cd todo-app
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Technologies

- Vue 3
- Vite
- SCSS
- LocalStorage API
